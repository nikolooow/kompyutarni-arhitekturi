# Каталог на компютърни конфигурации
**Предмет:** Компютърни архитектури  
**Проект:** Каталог от 5 специализирани PC конфигурации за различни потребителски сценарии.

## Описание на проекта
Настоящият проект съдържа подробни технически спецификации, обосновка на хардуерния избор и сравнение на цените от български онлайн магазини за 5 различни компютърни конфигурации:

1. **Бюджетен офис компютър** (до €800 / ~1560 лв.) — Ниска консумация, тишина и надеждност.
2. **Работна станция** (до €2000 / ~3900 лв.) — Много оперативна памет, бърз NVMe SSD и висока производителност при мултитаскинг.
3. **Геймърски компютър** (до €3000 / ~5860 лв.) — Мощна видеокарта за високи FPS и висока резолюция.
4. **Видео / 3D рендериране** (до €4000 / ~7820 лв.) — Оптимизиран за DaVinci Resolve, Blender и тежки изчисления.
5. **Домашен сървър** (до €1500 / ~2930 лв.) — Надежност 24/7, разширяемост за масиви от дискове и ECC памет.
